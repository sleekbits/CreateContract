# Sample Contract Template Format (.docx)

Use these placeholders exactly in your Microsoft Word template:

- {{contract_title}}
- {{contract_no}}
- {{contract_date}}
- {{client_name}}
- {{client_address}}
- {{contractor_name}}
- {{contractor_address}}
- {{start_date}}
- {{end_date}}
- {{contract_value}}
- {{scope_of_work}}
- {{payment_terms}}
- {{special_conditions}}
- {{prepared_by}}
- {{approved_by}}
- {{status}}

## Example header

```
{{contract_title}}
Contract No: {{contract_no}}
Date: {{contract_date}}
```

## Example body sections

```
Client: {{client_name}}
Address: {{client_address}}

Contractor: {{contractor_name}}
Address: {{contractor_address}}

Scope:
{{scope_of_work}}

Payment Terms:
{{payment_terms}}
```
